# Mentor Hub

" Nome do Projeto : Guerreiros Mentoria
Crie um protótipo de alta fidelidade para uma plataforma de mentoria de estudos, inspirado no design limpo e na estrutura de painéis visíveis em image_0.png.

Visão Geral do Design: Replicar a paleta de cores verde-água e branco de image_0.png, e o layout de barra lateral de navegação e conteúdo centralizado. A navegação deve ser intuitiva para um mentor e seus alunos.

Barra Lateral de Navegação (Personalizada para Mentoria):

Home (Dashboard) - Ícone de casa (exatamente como em image_0.png).

Turmas e Alunos - Ícone de grupo de pessoas. (Novo)

Conteúdos da Mentoria - Ícone de livro. (Substituindo 'Disciplinas' e 'Biblioteca')

Simulados e Exercícios - Ícone de teste/prancheta. (Consolidado)

Acompanhamento de Progresso - Ícone de gráfico. (Novo, focado em análise avançada)

Calendário de Mentoria - Ícone de calendário. (Novo, para agendar sessões)

Relatórios e Feedback - Ícone de balão de feedback. (Novo, para feedback individual)

Painel Central (Seção 'Pai'): Deve apresentar os principais KPIs que o mentor precisa ver imediatamente.

Cartões do Topo: Semelhante a image_0.png, mas com métricas de mentoria:

Cartão 1 (Esquerda): "Total de Alunos" e "Alunos Ativos".

Cartão 2 (Meio): "Progresso Médio das Matérias (Língua Portuguesa e outras)" - Usar um medidor de porcentagem como o de image_0.png.

Cartão 3 (Direita): "Média em Simulados".

Seção 'Constância nos Estudos' (Modificada): Usar a mesma representação de calendário de bolinhas verdes e vermelhas de image_0.png, mas com o título 'Assiduidade dos Alunos'.

Painel de Matérias/Conteúdos (Inspirado na Tabela):

Criar uma seção principal para 'Língua Portuguesa' (Título grande).

Abaixo, replicar a tabela de image_0.png com as colunas: "Subtópico (ex: Sintaxe, Morfologia)", "Tempo de Estudo do Aluno", "Questões Resolvidas ✅", "Questões Erradas ❌", "% de Acerto".

Adicionar um botão 'Adicionar Matéria' visível e intuitivo.

Barra Lateral Direita do Conteúdo: Replicar os painéis de image_0.png (Data da Prova, Metas, Estudo Semanal) com o mesmo layout, mas com dados de exemplo aplicáveis a um aluno sendo mentoreado."
